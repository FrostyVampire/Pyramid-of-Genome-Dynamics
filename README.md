# Pyramid-of-Genome-Dynamics
The repo contains 2 files:

SyntenyBlocksSimulations.py: simulates evolution using the 3 evolutionary types (jump, reversal, indel) and creates a graph comparing the synteny blocks generated by the simulation with the values calculated using the formula*
- The user is prompted with a window to select an evolutionary type and input lambda values for each selected event
- The user can also control the starting length of the simulated genome and how many times the simulation will be run before averaging the values
- The graph and results are then saved in an outputs folder

*The formula currently only supports jumps (with any segment length), reversals, and single-gene insertions/deletions. Including multiple events or increasing the segment length of indels beyond 1 will yield inaccurate formula results.

SBLD.py: includes the algorithm used to find the synteny block length distribution (SBLD) between 2 given genomes, as well as some secondary functions used on SBLD's and arrays containing synteny blocks

Required Python version and libraries:
- Python 3.10
- NumPy
- SciPy
- Matplotlib
